## Why it is not written yet

The shape is not decided, and the choice matters more than it looks. A
self-check is the first — often only — contact most readers have with the
criteria, and it sets what they think the criteria are.

Open questions:

- **What it produces.** A score, or a list of things to go and look at? A score
  is more satisfying and more likely to be quoted. It is also more likely to be
  quoted *wrongly* — "we scored 4/4 on Evaluator Integrity" from a
  ten-minute unverified self-assessment is a claim this project would then be
  supporting. A findings list is harder to misuse.
- **How it relates to the full criteria.** A faithful subset, a simplified
  proxy, or a set of pointers into the criteria? A proxy that disagrees with the
  full scoring is a defect that will be found and reported as one.
- **Whether results are self-reported anywhere.** Almost certainly not — an
  unverified self-report published under this project's name is the failure mode
  the criteria are about. Worth stating explicitly rather than leaving open.
- **Ten minutes.** Real constraint or aspiration? If four criteria cannot
  honestly be assessed in ten minutes, the honest answer is a longer check, not
  a thinner one.

## Constraint that already holds

Whatever this becomes, it is prose and criteria material: CC BY 4.0, written to
be quoted, and subject to the same freezing policy as
[`../criteria/README.md`](../criteria/README.md) if it ever carries a version
number people cite.
